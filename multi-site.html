개인별 월 세후 수령액

숙소별 입력

기존 계산기의 계약 6종·비용·그래프·비교 기능을 그대로 사용합니다.

숙소 입력은 자동 반영됩니다. 아래 편집기의 세후값은 해당 숙소 단독 참고값입니다. 여러 숙소의 소득을 합친 최종 추정치는 ‘사람별 합산’에서 확인하세요. 개인 공제·기타소득과 부가세 유형은 상위 화면에서 관리합니다.

사람별 합산

한 사람은 여러 숙소에 투자하거나 호스트를 겸할 수 있습니다.

공통 명단과 개인 세무 입력

금액은 연간 만원. 다른 종합소득에는 이 계산기의 숙소 소득을 중복 입력하지 마세요. 기타 금융소득은 국내 일반 14% 원천징수 이자·배당만 지원합니다.

전체 숙소를 합친 개인 정산

공제는 개인당 한 번 적용합니다. 임대사업·숙박사업·출자배당·대여이자를 함께 계산한 세금 증가분을 표시합니다. 숙소별 세금은 양수 소득금액 비율로 나눈 참고값이며, 세금 신고 단위가 아닙니다. 수익률·회수기간은 건물주 임대수익을 제외합니다.

투자자별 숙소 수익 비교

금액: 만원 · 수익률: 연 기준. 합계 수익률 = 연 수익 합계 ÷ 투자금 합계. 숙소별 세후액은 개인 합산세금 안분 후 금액입니다. 이 표는 임대수익을 제외한 운영·투자수익입니다. 임대료 포함 합계는 아래 표에서 확인하세요.

부가세 판정 그룹

같은 납세자의 과세유형 판단에 함께 들어가는 사업장을 묶으세요.

그룹은 운영 그룹·같은 호스트와 다릅니다. 공동사업자 구성 등 실제 납세 주체를 확인해 지정하세요. 여기서는 사업장별 과세를 전제합니다. 사업자단위과세·연중 개업·휴폐업·유형전환은 별도 검토 대상입니다.

‘자동 추정’은 직전연도 그룹 과세 공급대가를 기준으로 합니다. ‘올해와 같음’은 안정연도 가정입니다. 외부 매출은 판정에만 사용하며 이 포트폴리오 수익에 더하지 않습니다. 현재 등록유형과 다른 자동 결과는 실제 전환일까지 확정 적용되지 않습니다.

과세유형과 납부면제를 구분합니다

1억 400만원 기준은 그룹의 직전연도 과세 공급대가로, 4,800만원 미만 납부면제는 간이과세 사업장별 당해 과세 공급대가로 계산합니다. 면제는 면세사업 전환이 아닙니다. 면세 매출은 판정 매출에서 제외합니다. 과세 부동산임대가 있으면 4,800만원 기준·지역 배제 등을 확인하고 등록 과세유형을 직접 선택하세요. 명시적으로 선택한 현재 간이과세 유형은 12개월 유지하는 가정입니다.

계산 기준과 사용 순서

① 공통 명단 등록 → ② 숙소 추가·참여자 연결 → ③ 계약·매출·비용 입력 → ④ 부가세 판정 그룹 확인 → ⑤ 개인별 합산 결과 확인.

기존 계산기에서 확장한 것

  • 숙소 50개·공통 인원 100명, 숙소당 참여자 20명까지.
  • 숙소별 호스트·임차인·투자자와 계약 유형을 각각 설정.
  • 숙소별 보증금·수리비·운전자금·권리금·대여금 관리.
  • 기존 단일 계산기의 저장 JSON을 새 숙소로 가져오기.
  • 이름으로 자동 병합하지 않습니다. 가져온 뒤 참여자 연결을 확인하세요.

소득세 합산과 수익률

  • 이 계산으로 증가한 소득세·지방소득세만 차감합니다.
  • 출자공동사업 배당은 종합·비교과세, 대여이자는 일반 금융소득과 함께 기준을 판단합니다.
  • 원천징수는 선납액입니다. 최종 세금에서 다시 차감하지 않습니다.
  • 호스트 보수 포함 수익률과 투자수입만의 수익률을 구분합니다. 단독사업 겸임은 분리 불가로 표시합니다.
  • 회수기간은 수입으로 투자금만큼 버는 기간입니다. 보증금 반환·대여 원금상환 일정이 아닙니다.

국세청 안내 반영

  • 숙박업 소득은 매출에서 증빙 가능한 경비를 차감하는 장부 방식으로 추정합니다.
  • 개인에게 귀속되는 숙소 소득을 합산하며 공제를 중복 적용하지 않습니다.
  • 채널별 과세 숙박·면세 주택임대·과세 부동산임대를 구분합니다. 간이 부가가치율은 숙박 25%·부동산임대 40%, 적격 매입 공급대가 공제율 0.5%를 적용합니다.
  • 안내의 84.6%·17.3% 경비율은 2023년 예시이므로 자동 사용하지 않습니다.

별도 확인할 범위

  • 결손금 통산·이월, 세액공제·감면, 외국소득·배당가산, 건강보험료, 법인과세는 제외합니다. 손실이 있으면 합산 세금이 보수적으로 커질 수 있습니다.
  • 단순·기준경비율, 연 500만원 이하 장소대여 기타소득 특례를 자동 적용하지 않습니다.
  • 건물주·전대인·외부 용역업자의 별도 부가세와 보증금 간주임대료는 제외합니다. 건물주 임대소득은 사업용 임대 종합과세 모형이며 주택 비과세·분리과세는 자동 판단하지 않습니다.
  • 숙소별 적립금은 현금 유보이며 세무상 비용과 다릅니다.

모든 자료는 이 브라우저 안에서 처리합니다. 자동 저장이 제한되는 환경에서는 ‘전체 입력 저장’으로 JSON을 보관하세요. 여러 사용자의 동시 편집·로그인·서버 동기화 기능은 없는 로컬 계산기입니다.
